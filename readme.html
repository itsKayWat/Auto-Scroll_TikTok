TikTok Auto-Scroll

Enhance your TikTok viewing experience with automatic video progression

⭐Features

  • Automatically scrolls to the next video when the current one ends
  • Works in both feed and search results
  • Fullscreen mode support
  • Toggle comments visibility
  • Visual status indicator
  • Keyboard shortcuts for quick control

🔥How to Use

Keyboard Shortcuts

Toggle Auto-Scroll:Shift + S

Toggle Fullscreen:Shift + F

Best Practices

  • Works best in fullscreen mode for seamless viewing
  • Use the toggle switch in the extension popup or Shift+S to enable/disable
  • Green indicator shows when auto-scroll is active
